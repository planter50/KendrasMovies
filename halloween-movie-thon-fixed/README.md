# 2026 Halloween Movie-Thon

A single-file GitHub Pages website inspired by the handwritten Halloween movie list in the reference image.

## Important
This version has **no external CSS, JavaScript libraries, or Google Fonts**, so it should load correctly on GitHub Pages even if external resources are blocked.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/(root)`.
6. Save and open the Pages URL GitHub provides.

Click movies to mark them watched. Progress is stored in the browser's local storage.
